# Microsoft Sentinel Analytics Rules

This folder contains custom Microsoft Sentinel Analytics Rules developed and maintained for threat detection and security monitoring.

## Purpose

The objective of this folder is to centrally manage, version, and deploy custom Analytics Rules used within Microsoft Sentinel environments.

## Contents

Analytics Rules may include detections for:

- Microsoft Entra ID
- Microsoft 365
- Microsoft Defender XDR
- Windows and Linux systems
- Azure resources
- Network and firewall events
- Cloud services
- Custom applications and log sources
